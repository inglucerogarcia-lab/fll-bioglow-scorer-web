# FLL BIOGLOW Scorer

Scorer web interactivo en español para la temporada BIOGLOW 2026-2027 de FIRST LEGO League.

## Características

- ✅ **Registro de equipos**: Registra tu equipo y guarda el historial de puntajes.
- ✅ **15 misiones completas**: Todas las misiones de BIOGLOW 2026-2027 con sus variaciones.
- ✅ **Fichas de precisión**: Sección independiente con la tabla de puntuación.
- ✅ **Cálculo automático**: Suma de puntos en tiempo real.
- ✅ **Estadisticas**: Historial de puntajes, mejor puntaje, promedio y gráfica de avance.
- ✅ **Diseño responsive**: Compatible con ordenador, tablet y móvil.
- ✅ **Almacenamiento local**: Los datos se guardan en tu navegador sin envíos a servidores.

## Cómo usarlo

1. Abre `index.html` en tu navegador.
2. Registra tu equipo (nombre y número).
3. Marca cada objetivo conseguido en las misiones.
4. Selecciona el número de fichas de precisión.
5. Haz clic en "Guardar puntaje" para registrarlo.
6. Accede a la sección de estadísticas para ver tu historial y progreso.

## Publicar en GitHub Pages

- Ve a `Settings` del repositorio.
- Entra en `Pages`.
- Selecciona `Deploy from a branch`.
- Usa la rama `main` y la carpeta raíz `/`.
- Guarda y espera a que GitHub genere la URL.

> Este proyecto está pensado como apoyo para llevar el marcador. Comprueba siempre el reglamento oficial y las últimas actualizaciones de FIRST LEGO League.
